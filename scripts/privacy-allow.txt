# privacy-scan.ps1 的放行清单：每行一条 .NET 正则，不分大小写，从命中的位置（或它前面最多 64 个字符）起头匹配（\G）。
# 匹配上、并且把"整段命中"都盖住，就当作中性占位放行。不给 -AllowListFile 时 privacy-scan 默认加载这一份；
# 它对所有命中都生效（外部模式文件的条目，也包括内置的用户名 / 用户目录一类）。占位文字里含本机真实用户目录
# 或 \Users\<本机用户名> 时一律不放行。固定样式（令牌、私钥、公网 IP、邮箱）不看这份清单。
#
# 为什么需要：「盘符 + Users 目录」这样的宽模式也会命中代码里测路径脱敏用的占位。
# 这里只列"明显不是任何真人"的占位。清单里不能放任何真实的用户名或别的个人值；加条目前先想：
# 这个名字会不会是某个真人的用户名？会就别加，改测试里的写法（所以不收 x、ab、abc 这种太短、真有人叫的名字）。
# 路径分隔符三种写法都认：单反斜杠、Rust 字符串里转义过的双反斜杠、正斜杠。

# 占位符号：<用户>、省略号 / 上级目录，以及文字里被引号 / 反引号紧跟着的用户目录前缀
