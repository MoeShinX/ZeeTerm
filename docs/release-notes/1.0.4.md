ZeeTerm 1.0.4：新 Logo、AI 对话不再中途丢上下文、连接窗口显示 TCP 实时上下行，终端里的中文和链接对齐了，外加一批安全修复

### 新增

- 新 Logo：前面的窗口换成深色底加紫色 Z，任务栏、托盘、安装包的图标一起更新
- 网络连接窗口：TCP 连接显示每条连接的实时上传 / 下载速率，每 2 秒刷新（UDP 和用 netstat 读取时显示「—」）
- 主窗口里的对话框可以按住标题区域拖动，关掉再打开回到居中

### 改进

- AI 对话：只要不开新对话、不换智能体，上下文就一直保持。codex / opencode 的后台进程不会再把还在用的对话因为空闲关掉；进程意外退出后，下一条消息会自动接上原来的对话。切换执行主机、主机的终端重连后，会自动告诉智能体（不显示在对话里）
- 新建 / 编辑主机对话框更紧凑：控件和字号缩小，高度按内容自适应，不再在按钮上方空出一大块
- 顶部标签更精致：标签、序号、关闭按钮缩小，在标题栏里上下居中
- AI 面板在浅色皮肤下的提示文字（失败摘要、审批标题、重试提示）颜色加深，看得清楚

### 修复

- 终端：粗体中文、后备字体里的字和 emoji 不再把后面的文字挤歪；选中中文后面的链接，复制出来的内容和看到的一致
- 终端：拖动窗口或开关侧栏后，终端立刻按新尺寸排版并通知服务器
- 凭据页：点「新建密码 / 私钥文件 / 导入私钥」后，表单出现在列表上方，凭据多的时候也能看到
- AI 只读模式：`base64 -o` / `--output` 这类会写文件的用法会先问你
- 文件传输：服务器没有返回文件大小时，不再把已有的目标文件清空；源文件在传输前被删除时报错，目标不变
- 文件传输：删除远端目录时，服务器返回的异常文件名会让删除中止，不会删到所选目录之外
- 同步：更换同步存储后，第一次同步按「首次同步」处理，两边的数据都保留，不会把本地记录当成已删除

### macOS 预览版（Apple Silicon）

- 下载 `ZeeTerm-1.0.4-macos-arm64.zip`，解压后把 ZeeTerm 拖进「应用程序」，需要 macOS 14 或更新版本。也可以用 Homebrew：`brew install --cask moeshinx/tap/zeeterm`（更新用 `brew upgrade --cask zeeterm`）
- 这个版本**还没有经过 Apple 签名和公证**：第一次打开时，到「系统设置 → 隐私与安全性」点「仍要打开」
- macOS 上暂时不能在应用内自动更新：有新版本时 ZeeTerm 会提醒并打开下载页
