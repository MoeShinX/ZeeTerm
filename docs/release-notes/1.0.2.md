ZeeTerm 1.0.2：Windows 免安装版，同步可以停用，添加 AI 接口时自动获取模型

### 新功能

- Windows 免安装版：下载 `ZeeTerm-1.0.2-windows-x64-portable.zip`，解压到任意可写的文件夹就能用。数据放在程序旁边的 `data` 文件夹里，不写注册表，可以和安装版同时运行，也能在应用内自动更新。已保存的密码绑定当前 Windows 用户，换电脑请先在「备份」页导出离线备份文件
- 设置 → 同步加了「启用同步」开关：关掉后不再同步，存储连接、登录信息和主密码都保留；重新打开会马上同步一次
- 添加 AI 接口时，没填默认模型也能点「测试」：会先从接口拉取模型列表，并自动填好一个默认模型；「默认模型」旁边的「获取模型」按钮也能一键拉取
- macOS 和没有对应安装包的 Linux 安装方式：有新版本时会提醒，并打开下载页
- macOS：远端编辑器的快捷键（保存、跳到行、注释等）和终端字号缩放改用 Cmd

### 改进

- 更新窗口点「下载并安装」后，签名校验一通过就直接安装，不用再点一次
- 主机树：手动拖动或上移下移只会固定这一层开头的一段，其余的继续按名称自动排，新建的主机也会按名称排进去；按名称排时英文在前、数字其次、中文按拼音
- Anthropic 类型的接口地址填了结尾的 `/v1` 时会自动去掉
- 英文界面的更新窗口显示英文更新说明
- 去掉了「从 Z-SSH 导入」：ZeeTerm 是全新的产品，需要从 Z-SSH 迁移的话，请用 Z-SSH 的老版本

### 修复

- 终端最后一行被底部栏挡住、滚不到底；触控板轻微滚动时没反应
- 登录 shell 是 fish 等非 POSIX shell 时，服务器状态采集失败
- OpenWrt / BusyBox 上 CPU 核数显示不对
- 标签右键「移到文件窗口」会卡死闪退；程序崩溃时会在数据目录的 `logs\panic.log` 留下记录
- 内置助手通过网关使用 DeepSeek 模型时报错 400（`thinking` 参数）
- 服务器状态里的网速偏高好几倍
- 英文界面里服务器运行时间显示成中文
- Linux / macOS 上本地备份卡片的说明写成了「用 Windows 账户加密」

### macOS 预览版（Apple Silicon）

- 下载 `ZeeTerm-1.0.2-macos-arm64.zip`，解压后把 ZeeTerm 拖进「应用程序」，需要 macOS 14 或更新版本。也可以用 Homebrew：`brew install --cask moeshinx/tap/zeeterm`（更新用 `brew upgrade --cask zeeterm`）
- 这个版本**还没有经过 Apple 签名和公证**：第一次打开时，到「系统设置 → 隐私与安全性」点「仍要打开」
- macOS 上暂时不能在应用内自动更新：有新版本时 ZeeTerm 会提醒并打开下载页
