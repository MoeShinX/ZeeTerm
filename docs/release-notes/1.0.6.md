ZeeTerm 1.0.6：标签可以拖动换位，主机树跟着当前标签走，复制被折行的长链接不再断成两行

### 改进

- 标签栏：按住标签左右拖动就能换位置（像浏览器一样），松手保留新顺序，按 Esc 恢复原样；主窗口、独立终端窗口、文件窗口都可以。主窗口里终端标签和文件标签各自排序
- 主机树和属性面板跟着当前标签走：切换、关闭标签，新开连接，从独立窗口合并回来时，左边自动选中这个标签连的服务器；服务器在收起的分组里会自动展开并滚到能看见的地方。空白标签不改变选中

### 修复

- 终端：一行放不下、被折到下一行显示的长链接或长路径，复制出来还是完整的一串，不会在折行处多出换行
- AI 正在使用的终端标签不能拖出主窗口（拖到窗口外或别的终端窗口上会提示，松手后标签留在原处），免得对话和终端分在两个窗口里；在本窗口里换位照常

感谢 youbilin 贡献了这个版本里的多项改进。

### macOS 预览版（Apple Silicon）

- 下载 `ZeeTerm-1.0.6-macos-arm64.zip`，解压后把 ZeeTerm 拖进「应用程序」，需要 macOS 14 或更新版本。也可以用 Homebrew：`brew install --cask moeshinx/tap/zeeterm`（更新用 `brew upgrade --cask zeeterm`）
- 这个版本**还没有经过 Apple 签名和公证**：第一次打开时，到「系统设置 → 隐私与安全性」点「仍要打开」
- macOS 上暂时不能在应用内自动更新：有新版本时 ZeeTerm 会提醒并打开下载页
