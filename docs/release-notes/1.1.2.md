ZeeTerm 1.1.2：AI 和文件按钮挪到右上角，终端拖选跟着原文走、不再选出半个汉字，内部名字统一为 ZeeTerm

### 新增

- 界面：AI 助手和文件按钮挪到标题栏右上角（窗口按钮左边），和它们滑出的面板在同一边；侧栏顶部显示「主机」标题
- 设置：「关闭标签前确认」移到「常规」，「自动重连」移到「连接与网络」；「终端」页分成字体与排版、辅助显示、光标、输入与剪贴板四组

### 变更

- 程序、数据库、备份 / 导出文件、AI 工具和环境变量里的旧名 `zssh` 统一改成 `zeeterm`。第一次启动会自动把数据库 `zssh.db` 改名为 `zeeterm.db`，主机、凭据和设置都在；以前的本机自动备份照样能恢复，云同步文件名不变，新旧版本的设备可以继续互相同步
- 需要自己处理的两件事：
  - 设置过 `ZSSH_*` 环境变量的（如 `ZSSH_DATA_DIR`），改成 `ZEETERM_*`，旧名不再读取；
  - 在 Claude Code 里手动允许过 `mcp__zssh__*` 的，改为允许 `mcp__zeeterm__*`。
- 离线备份的默认扩展名改为 `.zeetermbak`（老备份照样能导入）；AI 在服务器上覆盖文件时留的备份改为 `.zeeterm-bak-*`，以前的 `.zssh-bak-*` 可以手动删除
- 免安装版和 Linux tar.gz 这一版里临时多带一份 `zssh-mcp`，让旧版本能在应用内顺利更新上来，下一个版本去掉

### 修复

- 终端：拖选更顺。持续输出时选中的内容会跟着原文走，不会卷进新输出；按住不动不会产生选区；不再选出半个汉字，行尾折行的中文也不会把前一个字带进来；拖到终端外面松手按松手位置结束，独立终端窗口也一样；终端画面改为缓存绘制，拖选和光标闪烁时更省力
- 设置：「终端」页的「恢复本页默认设置」不再顺带重置已经移到别页的「关闭标签前确认」「自动重连」

### macOS 预览版（Apple Silicon）

- 1.1.2 的 macOS 版稍后提供。在此之前，macOS 请继续使用 1.0.6：在 GitHub 发布页的 1.0.6 下载 `ZeeTerm-1.0.6-macos-arm64.zip`，或者用 Homebrew：`brew install --cask moeshinx/tap/zeeterm`
