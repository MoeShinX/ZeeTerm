ZeeTerm 1.0.7: command suggestions can share one history across all hosts, the shell integration can turn itself on after you connect, and a Microsoft outage no longer looks like an expired OneDrive login

### New

- Terminal command suggestions: Settings → Terminal → Command suggestions has a new "History scope" option. The default, "Separate per host", works as before; with "Shared by all hosts", commands you ran on any host are suggested on every host. Each scope keeps its own history, so switching does not lose what the other one has; history is still kept in memory only, never written to disk or synced
- Terminal command suggestions: the same section has a new "Enable shell integration after connecting" switch (off by default). When it is on, ZeeTerm sends the same line as "Enable Bash integration for this session" / "Enable Zsh integration for this session" for you when an SSH connection comes up, instead of you clicking it every time. To avoid typing into a terminal you are already using, it only sends once, and only when the login shell is confirmed to be Bash or Zsh, the output has gone quiet within 15 seconds of connecting, the cursor sits on an empty prompt, and you have not typed anything in that pane yet; if those conditions don't all hold it gives up, and you can still enable it by hand. Nothing is ever sent on Telnet or serial connections

### Fixed

- Sync: when Microsoft's services have an outage, ZeeTerm no longer says "OneDrive sign-in has expired" and pauses automatic sync. If Microsoft's servers reject a download or upload, it now reports that OneDrive is temporarily unavailable and retries on its own, without asking you to sign in again
- Sync: signing in to OneDrive again no longer asks you to set up the master password again for no reason (an occasional failure to look up the account during sign-in used to be treated as switching to a different sync account)
- Standalone terminal windows (terminal windows dragged out of the main window): confirming a multi-line paste after the connection dropped used to make the app quit; it now cancels the paste and tells you. Messages like this now also show up in standalone terminal windows (none were shown there before), in the top-right corner, and go away after a few seconds
- Interface: turning the system's animation setting on or off while ZeeTerm is running (Windows Settings → Accessibility → Visual effects → Animation effects; "Reduce motion" on macOS) takes effect right away, without restarting ZeeTerm

Thanks to yqk100 for suggesting the two command suggestion improvements.
