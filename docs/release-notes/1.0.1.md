ZeeTerm 1.0.1：新增 Linux 版，文件面板断线自动重连，双击选词更准确

### 新功能

- 新增 Linux 版（x86_64，Ubuntu 22.04 / Debian 12 及更新的发行版，Wayland 和 X11 都能用）：提供 `.deb` 安装包（`sudo apt install ./ZeeTerm-1.0.1-linux-x86_64.deb`）和免 root 的 `.tar.gz`；已保存的密码放在系统钥匙串里，支持应用内更新
- 文件面板断线时会显示「已断开」并自动重连一次；标签右键菜单、面板标题栏和刷新按钮都可以手动重连
- 独立的文件窗口标题栏新增「并排到终端」，一键放回终端旁边
- 文件面板的「显示本地栏」开关会被记住；上下排列时远端在上、本地在下

### 改进

- 终端里双击选词改成和 VS Code 的终端一致：网址、路径、带符号的字符串能整段选中，复制出来和看到的一样
- 更新窗口去掉「确认安装」这一步：签名校验通过后点一下「立即安装」即可
- 窄的文件面板里也始终显示当前所在目录
- 文件面板第一次连接失败后，修好再刷新或重开面板就能连上，不用关掉标签重连

### 修复

- Linux：本地复制文件时保留可执行权限；下载的文件权限不会比服务器上的更宽，也不会出现连自己都读不了的情况
- 设置页「还没有代理」的提示不会再把括号挤到下一行开头
- Linux：串口关闭后立即重新打开，不会再提示设备忙
