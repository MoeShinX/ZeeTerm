ZeeTerm 1.0.2: Windows portable version, a switch to turn sync off, automatic model lists when adding an AI endpoint

### New

- Windows portable version: download `ZeeTerm-1.0.2-windows-x64-portable.zip` and extract it to any folder you can write to. It keeps its data in a `data` folder beside the program, writes nothing to the registry, runs alongside an installed copy and updates itself in the app. Saved passwords are tied to your Windows user, so export an offline backup file from the Backup page before moving to another computer
- Settings → Sync has a new "Enable sync" switch: turn it off to stop syncing while keeping the storage connection, sign-in and master password; turning it back on syncs right away
- When adding an AI endpoint, "Test" works without a default model: it first fetches the endpoint's model list and fills in a default model for you. The "Fetch models" button next to "Default model" does the same in one click
- macOS, and Linux installs without a matching package: you are told about new versions and taken to the download page
- macOS: remote editor shortcuts (save, go to line, comment and so on) and terminal font zoom use Cmd

### Improved

- After you click "Download and install", the update installs as soon as its signature is verified, with no second click
- Host tree: dragging or Move Up / Move Down pins only the top of that level; everything else stays sorted by name, and new hosts are placed by name too. Name order is letters first, then numbers, then Chinese (by pinyin)
- A trailing `/v1` in an Anthropic endpoint's Base URL is removed automatically
- The update window shows English release notes when the interface is in English
- Importing from Z-SSH has been removed: ZeeTerm is a new product; to migrate from Z-SSH, use an older Z-SSH release

### Fixed

- The last terminal row was hidden under the bottom bars and you could not scroll to the bottom; small touchpad scrolls did nothing
- Server status failed when the login shell is fish or another non-POSIX shell
- Wrong CPU core count on OpenWrt / BusyBox
- "Move to file window" in the tab menu froze and crashed the app; crashes now leave a record in `logs\panic.log` in the data folder
- The built-in assistant got HTTP 400 (`thinking` parameter) with DeepSeek models behind a gateway
- Network speed in the server status read several times too high
- Server uptime was shown in Chinese in the English interface
- On Linux and macOS, the local backup card said backups are encrypted with the Windows account

### macOS preview (Apple Silicon)

- Download `ZeeTerm-1.0.2-macos-arm64.zip`, unzip it and drag ZeeTerm into Applications; macOS 14 or newer is required. Or use Homebrew: `brew install --cask moeshinx/tap/zeeterm` (`brew upgrade --cask zeeterm` to update)
- This build is **not signed or notarized by Apple yet**: the first time you open it, go to System Settings → Privacy & Security and click "Open Anyway"
- There is no in-app auto-update on macOS yet: ZeeTerm tells you when a new version is out and opens the download page
