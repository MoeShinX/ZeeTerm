ZeeTerm 1.0.7：命令建议可以共用所有主机的历史、连接后自动启用 Shell 集成，微软服务故障不再显示成 OneDrive 登录失效

### 新增

- 终端命令建议：设置 → 终端 →「命令建议」里新增「历史范围」。默认「按主机分开」，和以前一样；选「所有主机共用」后，在任何一台主机上都能看到别的主机执行过的命令。两种范围各记各的，切换时不会丢掉另一边已有的历史；历史仍然只放在内存里，不写盘、不同步
- 终端命令建议：同一节里新增「连接后自动启用 Shell 集成」（默认关闭）。打开后，SSH 连上时会自动发送「本次启用 Bash / Zsh 集成」那一行，不用每次手动点。为了不往正在用的终端里乱发，只在确认登录 shell 是 Bash / Zsh、连接后 15 秒内输出已经安静、光标停在空的提示符上、并且还没在这个窗格里输入过任何东西时才发一次；条件凑不齐就放弃，仍然可以手动启用。Telnet、串口不会发送任何东西

### 修复

- 同步：微软服务出故障时，不再显示「OneDrive 登录已失效」、暂停自动同步。下载或上传被微软的服务器拒绝时，现在报「暂时不可用」并自动重试，不用重新登录
- 同步：重新登录 OneDrive 后，不再莫名要求重新设置主密码（登录时偶发查不到账号信息，原来会被当成换了一个同步账号）
- 独立终端窗口（从主窗口拖出来的终端窗口）：多行粘贴弹出确认框后连接断了，再确认粘贴会让程序直接退出，现在会取消粘贴并提示；独立终端窗口里也能看到这类提示了（以前一条都不显示），显示在右上角，几秒后自动收起
- 界面：运行中切换系统的「动画效果」开关（Windows 设置 → 辅助功能 → 视觉效果；macOS 的「减弱动态效果」）会立即生效，不用重启 ZeeTerm

感谢 yqk100 提出命令建议的两项改进。
