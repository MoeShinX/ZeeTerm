ZeeTerm 1.0.9：服务器概览停靠在终端旁、快捷命令面板与命令历史、行号和时间戳、标出 AI 执行的命令，Codex 里的复制也能用了

### 新增

- 界面：服务器概览改成停靠在终端右边，打开后终端自动让出宽度，不再盖住右边的输出
- 文件：文件面板可以放在左侧边栏（设置 → 文件传输 →「停靠位置」，默认仍是右侧双栏）。放到左侧后，侧边栏顶部可以在「主机 / 文件」之间切换，「文件」页显示当前终端那台主机的文件列表；是否跟随终端目录仍按「跟随终端目录」设置
- 终端：快捷命令栏可以展开成面板，左边是分组、右边是命令和搜索框，高度可以拖动；收起后和原来的命令栏一样
- 终端：新增命令历史面板（状态栏「命令历史」按钮），列出这台主机执行过的命令，可以搜索，单击填回终端、「运行」直接执行。需要开着 Shell 集成才会记录，历史只在内存里
- 终端：窗格左边可以显示行号和时间戳（设置 → 终端 →「显示行号」「显示时间戳」，默认都关）。复制文字时不会带上行号
- 终端：标出 AI 执行的命令（设置 → 终端 →「标出 AI 执行的命令」，默认打开）。AI 在终端里执行命令时，开头标出是哪个智能体，结尾显示退出码和耗时；标记只在本机显示，不发给服务器

### 修复

- 终端：在 Codex、vim、tmux 里复制现在能写进本机剪贴板了。以前 Codex 全屏界面里选中复制、`/copy`、Ctrl+O 都没有效果。远端程序只能写、不能读本机剪贴板；不需要的话可以在「设置 → 终端 → 输入与剪贴板」里关掉「允许远端程序写入剪贴板（OSC 52）」
- 终端：同一台主机上有多个窗格在自动重连时，遇到密码错误这类要你处理的情况，其他窗格不会再多连一次、多弹一次提问
- 凭据：生成 SSH 密钥时注释的默认值改成「ZeeTerm」
- 界面和 AI 说明里残留的旧名「Z-SSH」都改成了「ZeeTerm」

### macOS 预览版（Apple Silicon）
