ZeeTerm 0.3.1 正式版

### 新功能

- 在线更新：自动检查新版本，下载后先验证签名再安装
- ZeePilot：自带的 AI 助手，填接口地址和 Key 就能用
- 从 Z-SSH 一键导入主机、密码、私钥和设置
- 进程管理：按 CPU / 内存排序，可结束进程，系统关键进程受保护
- 服务器概览新增「所有网络连接」
- 终端右上角显示到服务器的延迟

### 改进

- 界面全面打磨：图标化的标题栏和侧栏、设置与管理合成一页、欢迎页
- 主机属性改成单页表单，可以直接测试连接
- 主机显示发行版图标，主机树恢复连接线
- 标签显示序号和连接状态，右键菜单更完整
- 退出时提醒还连着的会话

### 修复

- 启动时不再多弹出一个命令行窗口
