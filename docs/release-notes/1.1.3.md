ZeeTerm 1.1.3：全局命令面板、从 SSH 配置导入主机、半透明终端背景，新增 Linux ARM64 和 Intel Mac 版

### 新增

- 命令面板：按 Ctrl+Shift+P（macOS 上 Cmd+Shift+P）打开，不在终端里时也可以按 Ctrl+K。输入几个字就能搜索已开的终端标签、主机、快捷命令、常用操作和所有设置项，中英文关键词都认
- 主机：可以从 OpenSSH 配置文件（`~/.ssh/config`）导入主机。侧栏顶部、主机页和欢迎页都有「从 SSH 配置导入」，在预览里勾选后一次建好；认得 `Include`、`ProxyJump`（含多级跳板）和 `IdentityFile`（只记路径，不读私钥），不会改动你的 ssh 文件
- 终端：终端背景可以调成半透明，透出后面的桌面（「设置 → 外观 → 终端背景透明」），可选模糊、透明，Windows 11 上还有 Mica。只有终端区域透明，默认和以前完全一样
- 终端：多行粘贴确认框里可以直接修改要粘贴的内容，Ctrl+Enter 粘贴；内容里有 Markdown 代码围栏时，可以一键去掉围栏行
- AI：终端里选中文字后，右键菜单可以「问 AI」；AI 回复里的代码块可以一键存为快捷命令
- 端口转发：「所有网络连接」里远端正在监听的端口，右键可以一键转发到本地，自动挑一个空闲的本机端口
- 进程列表：右键菜单新增「复制命令行」（完整命令行，不是列表里截短的那段）和「复制 PID」
- 反馈：「设置 → 关于」新增「报告问题」「功能建议」，用浏览器打开预填了版本和系统信息的 GitHub 页面；上次崩溃退出的话，下次启动会问要不要反馈，崩溃记录里的 IP、邮箱、主机地址和用户名等都已替换掉，提交前可以自己检查。ZeeTerm 自己不发任何网络请求
- 新平台（预览）：Linux ARM64（aarch64）的 `.deb` 和 `.tar.gz`，支持应用内更新；Intel Mac 版，见下面的 macOS 一节

### 变更

- 免安装版和 Linux tar.gz 里不再带上一版过渡用的 `zssh-mcp` 副本

### 修复

- 复制地址等应用内提示改为在窗口顶部居中显示，不再挤在右上角的窗口按钮下面
- 更新：Linux tar.gz 包在解压前会核对版本和架构，签名有效但不是本机对应的包会直接拒绝

### macOS（Apple Silicon / Intel，预览）

- 需要 Apple Silicon 的 Mac（M1 及更新）或 Intel Mac，macOS 14 或更新；Intel 版不是 Universal 包，请下载和自己 Mac 对应的 zip（`-macos-arm64.zip` 或 `-macos-x64.zip`）。
- 没有 Apple 开发者（Developer ID）签名，也没有公证，第一次打开会被系统拦下（提示无法验证开发者，或者提示已损坏）：在终端执行 `xattr -dr com.apple.quarantine /Applications/ZeeTerm.app` 后再打开；或者先双击一次，再到「系统设置 → 隐私与安全性」里点「仍要打开」（macOS 15 起右键「打开」已经不能放行）。
- 因为只有 ad-hoc 签名，每次更新到新版本后第一次启动，系统可能会问「ZeeTerm 想要使用钥匙串」，选「始终允许」即可。
- Apple Silicon 可以用 Homebrew 安装：`brew install --cask moeshinx/tap/zeeterm`（升级用 `brew upgrade --cask zeeterm`；第一次打开同样要先放行）；cask 暂时没有 Intel 版，Intel Mac 请下载 `-macos-x64.zip` 手动安装。
- 应用内只会提醒有新版本，不会自动更新：请到发布页下载，或者用 Homebrew 升级。

### Android（测试版）

- ZeeTerm 现在有 Android 测试版，需要 Android 8.0 或更新。安装包不在这个发布页，请到官网下载页获取：https://zeeterm.app/zh/download#android
- 测试版的功能还在完善，可能会有不稳定的地方，遇到问题欢迎到 GitHub Issues 反馈。
