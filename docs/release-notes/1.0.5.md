ZeeTerm 1.0.5：终端里可以切换中文输入法、按 Tab 补全不再跳走焦点，属性面板可以直接修改，新建凭据改成弹窗，外加一大批稳定性和安全修复

### 改进

- 主机属性面板：单击某一行的值就复制这一行；双击名称、地址、用户名、端口，直接在行上修改，回车或点别处保存（协议、密码、跳板机、代理仍在右键「属性…」里改）
- 设置 → 凭据：「新建密码 / 私钥文件 / 导入私钥」改成弹出对话框，回车保存、Esc 取消，凭据多的时候也不会找不到表单
- 新建 / 编辑主机对话框可以点外面的空白处关闭；有没保存的修改时会先问你
- 文件面板：在很大的目录里往过滤框打字不再卡顿
- 终端：鼠标停在链接上时会显示它真实指向的地址，显示文字和实际地址不一样的链接一眼就能看出来
- 终端：会话还连着时按 Ctrl+Shift+R 会先确认，免得误把正在跑的命令断掉
- SSH：保存的密码被拒、重新输入时，可以勾选「用这个密码更新保存的密码」

### 修复

- 终端：按 Tab / Shift+Tab 补全时，焦点不会再跳到别的控件
- 设置 → 连接与网络：第一次打开不再卡住几秒
- 服务器概览和 AI / 文件面板同时打开时，概览不再被挤变形
- 欢迎页和锁屏页显示新 Logo，高分屏下也清楚
- 文件面板：选「解压到同名文件夹」时，压缩包文件名里的特殊写法不会再被服务器当成命令执行
- 终端：可以切换到中文输入法打字了（进终端默认仍是英文，按输入法的切换键就能切回中文）
- 改界面语言等设置时，浅色界面不会再突然变成深色
- 终端：德语、法语等键盘上用 AltGr 打的 `@ \ ~ { } [ ]` 等字符能正常输入；服务器断线时屏幕不会再冻住不刷新
- 属性面板直接修改时可以按 Esc 取消，没改动就不会弹「已保存」
- 托盘：退出时在确认框里点了取消，托盘菜单不再失灵
- 文件面板：修改权限不再清掉 setuid / setgid / sticky 位；上传私钥这类文件时权限不会被放宽；解压时拒绝指向解压目录之外的符号链接；文件夹里有特殊编码的文件名时不再让整个传输失败
- SSH：保存的密码不对时会再问你一次；服务器发来的登录提示会标明来自服务器；主机名大小写写法不同不会再绕过指纹核对
- AI 助手：点「停止」之后，智能体再发来的命令一律不执行；跨行写的命令在只读模式下会先问你
- AI 助手：在设置里切到「全部放行」也要先确认；自己配置的接口如果用不在本机的 http 地址，会提示 API Key 会明文传输
- 同步：不再每次同步都做一次备份；OneDrive 改用账号 ID 区分（升级后第一次同步会按首次同步合并，两边的数据都保留）；在一台设备上忘记的主机指纹会同步到其他设备

感谢 youbilin 贡献了这个版本里的多项改进。

### macOS 预览版（Apple Silicon）

- 下载 `ZeeTerm-1.0.5-macos-arm64.zip`，解压后把 ZeeTerm 拖进「应用程序」，需要 macOS 14 或更新版本。也可以用 Homebrew：`brew install --cask moeshinx/tap/zeeterm`（更新用 `brew upgrade --cask zeeterm`）
- 这个版本**还没有经过 Apple 签名和公证**：第一次打开时，到「系统设置 → 隐私与安全性」点「仍要打开」
- macOS 上暂时不能在应用内自动更新：有新版本时 ZeeTerm 会提醒并打开下载页
