ZeeTerm 1.0.3: command suggestions in the terminal, a rounder look and the Lavender light skin, more accurate "Test Connection" results, plus a large batch of stability and security fixes

### New

- Command suggestions in the terminal: type at least two characters on the shell's input line and pause, and a list next to the cursor shows commands you have used on this host plus your quick commands (prefix matches only, up to 8, nothing preselected). Plain Tab, Enter and arrow keys still go to the shell; click "Select" on the list or in the status bar (or bind your own shortcut in Settings) to enter select mode, then pick with ↑↓ and press Tab / Enter. **Only the rest of the command is filled in; it is never executed**
- Command history is kept in memory only: it is not written to disk, not synced and not shared between hosts. Commands starting with a space, and commands containing passwords, tokens or keys, are never recorded or suggested. Quick commands can be excluded from suggestions
- Suggestions rely on input-line markers sent by the shell; without them there are no suggestions and no keys are intercepted. For Bash / Zsh you can enable them for the current session from "Command Suggestions" in the status bar (remote config files are not changed). Settings → Terminal → "Command Suggestions" turns suggestions or history off and clears history
- A rounder look: inputs, buttons, menus, panels, tabs and the sidebar share rounder shapes, and the host list uses cards; on dark skins, input borders and menus stand out more clearly
- New light skin Lavender (purple accent), available in Settings → Appearance

### Improved

- "Test Connection" in the new / edit host dialog no longer fails for a server you have never connected to and whose fingerprint is not saved yet. The test stops as soon as it receives the server's host key, without logging in or saving the fingerprint, and reports that the network and SSH service respond and that login will be verified on the first connection. Login is only tested when the fingerprint matches the saved one
- Test results are shown as complete, partial, failed or cancelled, with separate lines for connectivity, server identity and login. A missing password or a one-time code request is reported as "login needs interactive verification", not as a wrong password; a configured password or key that the server rejects is reported as an authentication failure
- Changing the address, port, user, password, authentication method, proxy or jump host while a test is running stops the test and discards its result; a late result no longer fills in a dialog that was closed and reopened

### Fixed

- AI read-only mode: commands written with the redirect attached (such as `cat>file`) no longer slip past the read-only check; commands that may print secrets or environment variables now ask first
- File transfers: odd file names from the server can no longer write outside the chosen folder; retrying a failed cross-host copy keeps the source host; progress and target files stay correct across pause, retry and cancel; folders nested too deeply now fail with a clear error instead of being skipped silently
- File transfers: "preserve permissions" uses the real file mode; the target name is claimed before writing, so a file that appears at the same time is not overwritten; when a retry renames the target, the previous attempt's temporary file is removed
- Remote editor: drafts and reconnects stay bound to the server the file was opened on; "Save As" on a conflict only ever creates a new file
- Saving a host, credential or other multi-step change either fully succeeds or changes nothing; editing a credential that was deleted reports an error instead of quietly creating a new one
- SSH: appending to a `known_hosts` file without a trailing newline no longer corrupts the last line; a dropped connection during key login is reported instead of falling back to a password prompt; remote port-forward requests time out
- Sync: a conflict that cannot be decrypted is shown as "unreadable" instead of "deleted"; closing the window right after a manual sync no longer loses data
- App lock: if the lock settings cannot be read, the app stays locked instead of treating the lock as off
- Telnet / serial: no more crashes on multibyte (for example Chinese) characters
- AI assistant: a stuck agent probe is terminated; agent downloads can be cancelled; memory use during long conversations is capped; the standalone AI window queues messages and switches agents like the panel
- Quitting from the tray uses the same shutdown path as closing the main window; windows no longer reopen off-screen after a second monitor is unplugged; terminal status messages are shown in release builds too

### macOS preview (Apple Silicon)

- Download `ZeeTerm-1.0.3-macos-arm64.zip`, unzip it and drag ZeeTerm into Applications; macOS 14 or newer is required. Or use Homebrew: `brew install --cask moeshinx/tap/zeeterm` (`brew upgrade --cask zeeterm` to update)
- This build is **not signed or notarized by Apple yet**: the first time you open it, go to System Settings → Privacy & Security and click "Open Anyway"
- There is no in-app auto-update on macOS yet: ZeeTerm tells you when a new version is out and opens the download page
