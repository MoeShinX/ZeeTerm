ZeeTerm 1.0.8: SSH sessions reconnect automatically after an unexpected drop, closing a connection that is in use asks first, and the interface text size can be changed

### New

- Terminal: when an SSH connection drops unexpectedly (network outage, keep-alive timeout, server reboot), ZeeTerm now reconnects on its own (Settings → Terminal → "Auto-reconnect", on by default). The disconnected screen shows "Reconnecting in Ns (attempt k)"; the first attempt comes after 3 seconds, then the wait grows to 30 seconds, for up to 10 attempts (about 4 minutes). You can still press R or click the screen to reconnect by hand, or click "Cancel" to stop. A normal exit of the remote shell (for example typing exit), a disconnect you asked for, Telnet and serial connections never reconnect automatically; if something needs you (a wrong password, a changed host key) it stops right away instead of prompting again and again. The earlier output is still there after reconnecting
- Terminal: closing a connection that is in use now asks first (Settings → Terminal → "Confirm before closing a tab", on by default). Closing a tab or a pane, closing several at once (Close Others / to the Left / to the Right / All), or closing a standalone terminal window shows a confirmation when any of them is connected or still connecting, saying how many connections will be closed; Enter closes, Esc cancels, and ticking "Don't ask again" turns it off. Tabs that are already disconnected still close right away
- Interface: Settings → Appearance has a new "Interface Text Size" option with Small / Default / Large (Default is the same as before). It applies immediately to every open window. It only changes interface text; the terminal font size is still set under Terminal

### Fixed

- Server overview: memory, swap and disk under 1 GB are shown in MB (for example "512MB") instead of "0.5GB" or "0.1GB"

### macOS preview (Apple Silicon)

- Download `ZeeTerm-1.0.8-macos-arm64.zip`, unzip it and drag ZeeTerm into Applications; macOS 14 or later is required. Or use Homebrew: `brew install --cask moeshinx/tap/zeeterm` (update with `brew upgrade --cask zeeterm`)
- This build is **not yet signed or notarized by Apple**: the first time you open it, go to System Settings → Privacy & Security and click "Open Anyway"
- In-app updates are not available on macOS yet: when a new version is out, ZeeTerm tells you and opens the download page
