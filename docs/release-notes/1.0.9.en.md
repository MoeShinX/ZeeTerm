ZeeTerm 1.0.9: the server overview docks beside the terminal, a quick command panel and command history, line numbers and timestamps, AI commands are marked in the terminal, and copying from Codex works

### New

- Interface: the server overview now docks on the right of the terminal. The terminal gives up the width it needs instead of being covered
- Files: the file panel can be placed in the left sidebar (Settings → File Transfer → "Dock position"; the right-hand two-pane layout is still the default). In the sidebar you can switch between "Hosts" and "Files", and the Files page lists the files of the host in the current terminal. Whether it follows the terminal's directory is still up to the "Follow terminal directory" setting
- Terminal: the quick command bar can expand into a panel with groups on the left and commands plus a search box on the right; its height can be dragged. Collapsed, it is the same bar as before
- Terminal: a new command history panel (the "Command History" button in the status bar) lists the commands run on this host. You can search it, click to put a command back into the terminal, or use "Run" to run it. Commands are recorded only while shell integration is on, and the history stays in memory
- Terminal: line numbers and timestamps can be shown on the left of each pane (Settings → Terminal → "Show line numbers" / "Show timestamps", both off by default). Copied text never includes them
- Terminal: commands run by AI are marked in the terminal (Settings → Terminal → "Mark commands run by AI", on by default). The start shows which agent ran it and the end shows the exit code and how long it took. The marks are only drawn locally and never sent to the server

### Fixed

- Terminal: copying in Codex, vim and tmux now reaches your local clipboard. Before, selecting and copying, `/copy` and Ctrl+O inside Codex's full-screen view did nothing. Remote programs can only write your clipboard, never read it; if you don't want this, turn off "Allow remote programs to write the clipboard (OSC 52)" under Settings → Terminal → Input & Clipboard
- Terminal: when several panes on the same host are reconnecting and one hits something that needs you, such as a wrong password, the others no longer try once more and ask again
- Credentials: the default comment for a generated SSH key is now "ZeeTerm"
- The last places in the interface and the AI instructions that still said the old name "Z-SSH" now say "ZeeTerm"

### macOS preview (Apple Silicon)

- The macOS build of 1.0.9 will be added later. Until then, please keep using 1.0.6 on macOS: download `ZeeTerm-1.0.6-macos-arm64.zip` from the 1.0.6 release on GitHub, or use Homebrew: `brew install --cask moeshinx/tap/zeeterm`
