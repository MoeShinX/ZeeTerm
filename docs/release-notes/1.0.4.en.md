ZeeTerm 1.0.4: a new logo, AI conversations that keep their context, live per-connection TCP rates, Chinese text and links that line up in the terminal, plus a batch of security fixes

### New

- New logo: the front window is now dark with a violet Z; the taskbar, tray and installer icons are updated too
- Network connections window: TCP connections show live upload / download rates, refreshed every 2 seconds (UDP and netstat sources show "—")
- Dialogs in the main window can be dragged by their title area; they return to the centre when reopened

### Improved

- AI conversations keep their context until you start a new chat or switch agents. The codex / opencode background process no longer closes a conversation that is still in use when it goes idle, and if the process exits unexpectedly, your next message picks the conversation up again. Switching the target host, or a host's terminal reconnecting, is passed on to the agent automatically (not shown in the chat)
- The new / edit host dialog is more compact: smaller controls and text, and its height follows the content instead of leaving a gap above the buttons
- Tabs are more refined: smaller tabs, numbers and close buttons, centred in the title bar
- Notices in the AI panel on light skins (failure summaries, approval titles, retry hints) use a darker colour that is easy to read

### Fixed

- Terminal: bold Chinese text, characters from fallback fonts and emoji no longer push the following text sideways; selecting a link after Chinese text copies exactly what you see
- Terminal: after resizing the window or toggling a sidebar, the terminal lays out at the new size right away and tells the server
- Credentials page: after clicking "New Password", "Key File" or "Import Key", the form appears above the list, so it stays visible when you have many credentials
- AI read-only mode: `base64 -o` / `--output` and other uses that write files now ask first
- File transfers: when the server does not report a file's size, an existing target is no longer emptied; if the source is deleted before the transfer, it fails and the target is left alone
- File transfers: when deleting a remote folder, an odd file name from the server stops the deletion instead of reaching outside the chosen folder
- Sync: after switching to a different sync storage, the first sync is treated as a first sync and keeps the data on both sides, instead of treating local records as deleted

### macOS preview (Apple Silicon)

- Download `ZeeTerm-1.0.4-macos-arm64.zip`, unzip it and drag ZeeTerm into Applications; macOS 14 or later is required. Or use Homebrew: `brew install --cask moeshinx/tap/zeeterm` (update with `brew upgrade --cask zeeterm`)
- This build is **not yet signed or notarized by Apple**: the first time you open it, go to System Settings → Privacy & Security and click "Open Anyway"
- In-app updates are not available on macOS yet: when a new version is out, ZeeTerm tells you and opens the download page
