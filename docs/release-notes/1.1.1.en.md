ZeeTerm 1.1.1: file-type icons in the file lists, a resizable transfer queue, recent hosts on the welcome page, and a safer read-only auto mode for AI

### New

- Files: the file lists show an icon per file type. On Windows it is the system-associated icon, as in Explorer and Xftp (looked up by extension only, the file itself is never read); for types with no association, and on Linux, a built-in category icon, with archives told apart as zip / tar / 7z / rar / gz
- Files: the divider between the file list and the transfer queue can be dragged up and down; double-click resets it, and the height is remembered
- Interface: the welcome page lists the 4 most recently used hosts; click one to open it
- Interface: status bar figures use a monospaced font so they no longer shift as they change; SSH hosts no longer show a repeated "SSH" tag on their cards; the terminal font list now offers Maple Mono, Sarasa Term SC, Geist Mono and Hack

### Fixed

- AI assistant: read-only auto mode no longer runs commands that would hold the terminal forever (such as `top` or `ping` without a count, `tail -f`, `journalctl -f`, `docker logs -f`) on its own; it asks you first. With options that make them finish (such as `top -b -n 1` or `ping -c 4`) they still run automatically
- Updates: the signature check now also matches the installer file name recorded in the signature, and old-format signatures are no longer accepted
- Port forwarding: traffic is counted live, so long-running connections show their traffic; remote forwards are also capped at 256 concurrent connections
- Remote editing: "Save as" after an edit conflict never overwrites a file someone else just created with the same name
- Terminal: three fixes for the line number / timestamp gutter. Resizing the window no longer overwrites the times of older lines, lowering the scrollback limit no longer makes line numbers go back, and line numbers and times stay correct after full-screen programs print a lot at once
- Interface:
  - the main window no longer redraws in full on every burst of terminal output, so the interface is smoother;
  - buttons show a clear outline when focused with Tab;
  - small text is no longer blurry with the Small interface text size;
  - green status badges use a light green fill with dark green text, and status bar warnings use a more readable amber;
  - copy buttons in AI replies show "Copied" after a click.
- Security: plaintext returned by the Windows lock prompt and Windows data protection is reliably wiped after use

### macOS preview (Apple Silicon)

- The macOS build of 1.1.1 will be added later. Until then, please keep using 1.0.6 on macOS: download `ZeeTerm-1.0.6-macos-arm64.zip` from the 1.0.6 release on GitHub, or use Homebrew: `brew install --cask moeshinx/tap/zeeterm`
