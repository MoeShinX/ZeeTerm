ZeeTerm 1.1.1：文件列表按类型显示图标、传输队列可以拖动调高度、欢迎页显示最近连接，AI 只读自动模式更安全

### 新增

- 文件：文件列表按文件类型显示图标。Windows 上和资源管理器、Xftp 一样显示系统关联的图标（只按扩展名查，不读文件本身）；没有关联的类型，以及 Linux 上，用内置的分类图标，压缩包按 zip / tar / 7z / rar / gz 分色
- 文件：文件列表和传输队列之间可以上下拖动，调整两边的高度；双击恢复默认，拖出来的高度会记住
- 界面：欢迎页显示最近用过的 4 台主机，点一下直接打开
- 界面：状态栏的数字改用等宽字体，变化时不再左右跳；主机卡片上 SSH 主机不再重复显示「SSH」标签；终端字体下拉多了 Maple Mono、Sarasa Term SC、Geist Mono、Hack

### 修复

- AI 助手：「只读自动」模式不再自动执行会一直占着终端的命令（比如不带次数的 `top`、`ping`，`tail -f`、`journalctl -f`、`docker logs -f`），改为先请你确认；带上能让它们自己结束的参数（如 `top -b -n 1`、`ping -c 4`）照常自动执行
- 更新：验签时还会核对签名里记录的安装包文件名，并且不再接受旧格式的签名
- 端口转发：流量改为实时计数，长时间开着的连接也能看到流量；远程转发也限制同时最多 256 条连接
- 远端编辑：保存冲突时「另存为」不会覆盖别人刚建的同名文件
- 终端：行号 / 时间戳栏修了三处问题：改窗口宽度后旧行的时间不再被覆盖、调小回滚行数后行号不再倒退、全屏程序大量输出后行号和时间保持正确
- 界面：
  - 终端大量输出时不再反复重画整个主窗口，界面更顺；
  - 用 Tab 切换焦点时按钮有清晰的轮廓；
  - 「小」字号下的说明文字不再发糊；
  - 绿色状态徽标改成淡绿底、深绿字，状态栏告警换成更易读的琥珀色；
  - AI 回复里的复制按钮点了会显示「已复制」。
- 安全：系统锁屏验证和 Windows 数据保护解出来的明文，用完后可靠地清零

### macOS 预览版（Apple Silicon）

- 1.1.1 的 macOS 版稍后提供。在此之前，macOS 请继续使用 1.0.6：在 GitHub 发布页的 1.0.6 下载 `ZeeTerm-1.0.6-macos-arm64.zip`，或者用 Homebrew：`brew install --cask moeshinx/tap/zeeterm`
