ZeeTerm 1.1.2: AI and Files buttons at the top right, terminal selections that stay on their text and never split a Chinese character, and internal names unified as ZeeTerm

### New

- Interface: the AI assistant and Files buttons moved to the top right of the title bar (left of the window buttons), on the same side as the panels they open; the sidebar header shows a "Hosts" title
- Settings: "Confirm before closing a tab" moved to General and "Auto reconnect" to Connection; the Terminal page is split into Font & Layout, Overlays, Cursor, and Input & Clipboard

### Changed

- The old internal name `zssh` in the program, database, backup and export files, AI tools and environment variables is now `zeeterm`. On first start the database `zssh.db` is renamed to `zeeterm.db` automatically, so hosts, credentials and settings are kept; earlier local automatic backups can still be restored, and the cloud sync file name is unchanged, so new and old versions keep syncing with each other
- Two things to do yourself:
  - if you set `ZSSH_*` environment variables (such as `ZSSH_DATA_DIR`), rename them to `ZEETERM_*`; the old names are no longer read;
  - if you allowed `mcp__zssh__*` in Claude Code, allow `mcp__zeeterm__*` instead.
- Offline backups now default to the `.zeetermbak` extension (old backups still import); backups the AI leaves on servers when overwriting files are now `.zeeterm-bak-*`, and older `.zssh-bak-*` files can be deleted by hand
- This release's portable zip and Linux tar.gz carry an extra copy of `zssh-mcp` so older versions can update in the app; it goes away in the next release

### Fixed

- Terminal: smoother drag selection. While output keeps scrolling, the selection stays on the original text instead of taking in new output; holding the button without moving never creates a selection; a Chinese character is never split, and a wide character wrapped to the next line no longer drags the character before it in; releasing outside the terminal ends the selection at the release point, in detached terminal windows too; the terminal is now painted from a cache, so dragging and cursor blink take less work
- Settings: "Restore Page Defaults" on the Terminal page no longer resets "Confirm before closing a tab" and "Auto reconnect", which now live on other pages

### macOS preview (Apple Silicon)

- The macOS build of 1.1.2 will be added later. Until then, please keep using 1.0.6 on macOS: download `ZeeTerm-1.0.6-macos-arm64.zip` from the 1.0.6 release on GitHub, or use Homebrew: `brew install --cask moeshinx/tap/zeeterm`
