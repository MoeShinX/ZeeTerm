ZeeTerm 1.0.6: drag tabs to reorder them, the host tree follows the current tab, and copying a long link that wraps no longer splits it in two

### Improved

- Tab bar: hold a tab and drag it left or right to move it (just like a browser); release to keep the new order, or press Esc to put it back. Works in the main window, standalone terminal windows and the file window. In the main window, terminal tabs and file tabs are reordered separately
- The host tree and info panel follow the current tab: when you switch or close tabs, open a connection, or merge a tab back from another window, the server that tab is connected to is selected on the left; if it sits in a collapsed group, the group opens and the server scrolls into view. A blank tab leaves the selection alone

### Fixed

- Terminal: a long link or path that is too wide for one line and wraps onto the next is copied as one piece, without an extra line break where it wrapped
- A terminal tab the AI is working in can no longer be dragged out of the main window (dragging it outside or onto another terminal window shows a hint and the tab stays put), so the conversation and the terminal don't end up in different windows; reordering within the window still works

Thanks to youbilin for contributing several of the improvements in this release.

### macOS preview (Apple Silicon)

- Download `ZeeTerm-1.0.6-macos-arm64.zip`, unzip it and drag ZeeTerm into Applications; macOS 14 or later is required. Or use Homebrew: `brew install --cask moeshinx/tap/zeeterm` (update with `brew upgrade --cask zeeterm`)
- This build is **not yet signed or notarized by Apple**: the first time you open it, go to System Settings → Privacy & Security and click "Open Anyway"
- In-app updates are not available on macOS yet: when a new version is out, ZeeTerm tells you and opens the download page
