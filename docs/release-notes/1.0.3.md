ZeeTerm 1.0.3：终端内命令建议、圆润界面和 Lavender 浅色皮肤，「测试连接」结果更准确，外加一大批稳定性和安全修复

### 新增

- 终端内命令建议：在 shell 输入行上打两个字以上、停一下，光标旁会列出这台主机用过的命令和你的快捷命令（只做前缀匹配，最多 8 条，不预选）。普通的 Tab、Enter、方向键照常交给 shell；点浮层或状态栏上的「选择建议」（也可以在设置里自己绑一个快捷键）才进入选择模式，用 ↑↓ 选、Tab / Enter 填入，**只填入后面的部分，不会回车执行**
- 命令历史只存在内存里：不写盘、不同步、不跨主机，以空格开头的命令和带密码、令牌、密钥的命令不会被记下也不会出现在建议里。快捷命令可以勾「排除自动建议」
- 建议依赖 shell 发来的输入行标记：没有标记时不出建议、不拦任何键。Bash / Zsh 可以从状态栏「命令建议」里为当前会话临时启用（不改远端的配置文件）。设置 → 终端 →「命令建议」可以关掉自动建议、关掉历史记录、清除历史
- 圆润界面：输入框、按钮、菜单、面板、标签、侧栏统一成更圆的样式，主机列表改成卡片；深色皮肤下输入框和菜单的边界更清楚
- 新增浅色皮肤 Lavender（紫色强调色），可在设置 → 外观里选

### 改进

- 新建 / 编辑主机的「测试连接」：第一次连、还没保存过指纹的服务器不再算失败。测试拿到服务器的主机密钥就停下，不登录、不保存指纹，显示「网络与 SSH 响应检测通过，登录待首次连接验证」；指纹和已保存的一致时才继续验证登录
- 「测试连接」的结果分成完成、部分完成、失败、取消，并分别列出连通性、服务器身份、登录三项。没填密码或需要验证码时显示「登录需要交互验证」，不再说成密码错误；已配置的密码或私钥被服务器拒绝时明确显示认证失败
- 「测试连接」进行中改了地址、端口、账号、密码、认证方式、代理或跳板机，测试会终止，旧结果作废；关掉再打开对话框，迟到的结果不会填回来

### 修复

- AI 只读模式：`cat>文件` 这类命令和重定向连写的写法不再绕过只读拦截；可能输出密钥、环境变量的命令执行前会先问你
- 文件传输：服务器返回的异常文件名不能把文件写到所选目录之外；跨主机复制失败后重试不再丢掉源主机；暂停、重试、取消后进度和目标文件保持正确；目录层数过深时明确报错，不再悄悄跳过
- 文件传输：保留权限时使用真实的文件权限；写入前先占住目标文件名，不会覆盖同时出现的同名文件；重试改了文件名时清掉上次留下的临时文件
- 远端编辑器：草稿和重连绑定打开时的服务器，换了服务器不会写错地方；冲突时「另存为」只会新建文件
- 保存主机、凭据等多步操作要么全部成功要么全部不改；编辑一个已删除的凭据时会报错，不会悄悄新建一条
- SSH：`known_hosts` 末尾没有换行时追加不再拼坏上一行；私钥登录遇到断线时直接报错，不再转去问密码；远程端口转发的请求有超时
- 同步：解不开的冲突显示为「无法读取」而不是「已删除」；手动同步后马上关窗口也不会丢数据
- 锁屏：读取设置失败时保持锁定，不再当成没开锁屏
- Telnet / 串口：遇到中文等多字节字符时不再崩溃
- AI 助手：检测智能体时卡住的进程会被结束；下载智能体可以取消；长时间对话的内存占用有上限；独立 AI 窗口和面板一样支持排队和切换智能体
- 托盘「退出」和关闭主窗口走同一套收尾流程；拔掉副屏后窗口不会恢复到看不见的位置；终端的状态提示在正式版里也会显示

### macOS 预览版（Apple Silicon）

- 下载 `ZeeTerm-1.0.3-macos-arm64.zip`，解压后把 ZeeTerm 拖进「应用程序」，需要 macOS 14 或更新版本。也可以用 Homebrew：`brew install --cask moeshinx/tap/zeeterm`（更新用 `brew upgrade --cask zeeterm`）
- 这个版本**还没有经过 Apple 签名和公证**：第一次打开时，到「系统设置 → 隐私与安全性」点「仍要打开」
- macOS 上暂时不能在应用内自动更新：有新版本时 ZeeTerm 会提醒并打开下载页
