ZeeTerm 1.0.1: Linux version, automatic reconnect for the file panel, more accurate double-click selection

**This is the first public release of ZeeTerm, with builds for Windows, Linux and macOS.** ZeeTerm is a native SSH, SFTP, Telnet and serial terminal client written in Rust and rendered with GPUI: no Electron, no WebView2, no embedded browser.

### New

- Linux version (x86_64; Ubuntu 22.04 / Debian 12 or newer; Wayland and X11): a `.deb` package (`sudo apt install ./ZeeTerm-1.0.1-linux-x86_64.deb`) and a `.tar.gz` that installs without root. Saved passwords are kept in the system keyring, and in-app updates are supported
- When the file panel loses its connection it shows "Disconnected" and reconnects once automatically; you can also reconnect from the tab's context menu, the panel title bar or the refresh button
- The title bar of a detached file window has a new "Dock beside terminal" button that puts it back next to the terminal
- The file panel remembers whether the local pane is shown; in the stacked layout the remote pane is on top and the local pane below

### Improved

- Double-click selection in the terminal now matches the VS Code terminal: URLs, paths and strings with symbols are selected as a whole, and what you copy is exactly what you see
- The update window no longer has a separate "Confirm install" step: once the signature is verified, one click on "Install now" is enough
- Narrow file panels always show the current folder
- If the file panel fails to connect the first time, refreshing or reopening it connects once the problem is fixed; there is no need to close the tab

### Fixed

- Linux: local copies keep the executable bit; downloaded files are never given wider permissions than on the server, and never end up unreadable for their owner
- The "No proxies yet" hint in Settings no longer pushes a closing bracket onto a new line
- Linux: reopening a serial port right after closing it no longer reports that the device is busy

### macOS preview (Apple Silicon)

- Download `ZeeTerm-1.0.1-macos-arm64.zip`, unzip it and drag ZeeTerm into Applications; macOS 14 or newer is required. Or use Homebrew: `brew install --cask moeshinx/tap/zeeterm`
- This build is **not signed or notarized by Apple yet**: the first time you open it, macOS blocks it. Go to System Settings → Privacy & Security, scroll to the bottom and click "Open Anyway"; after that it opens normally
- When you save a password (and the first time you start a new version), macOS may ask whether ZeeTerm may use your keychain; choose "Always Allow"
- There is no in-app auto-update on macOS yet: download the new version from the releases page and replace ZeeTerm in Applications (or run `brew upgrade --cask zeeterm` if you installed it with Homebrew). Your data and saved hosts are kept
