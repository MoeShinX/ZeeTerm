ZeeTerm 0.3.5：英文界面、终端搜索与清屏、文件面板重新设计、设置页重新分类

### 新功能

- 界面支持英文：默认跟随系统语言，中文系统显示中文，其他语言显示英文；可以在「设置 → 常规 → 语言」里手动选择。安装向导也有英文版
- 终端右键菜单新增「搜索」和「清屏」：搜索可以查到回滚记录里的内容，支持区分大小写、上一个 / 下一个；清屏只清本地屏幕，不发送任何内容到服务器
- 断线重连后保留之前的终端输出，中间插一行「已重新连接」分隔
- 分屏时右键菜单可以直接「关闭窗格」
- 文件面板默认同时显示本地和远端，宽的时候左右排列、窄的时候上下排列；本地栏默认打开「下载」文件夹
- 「设置 → 文件传输 → 文件面板」可以选择打开位置（终端右侧 / 新标签页 / 独立窗口）、是否显示本地栏、排列方式、本地默认目录（下载文件夹 / 上次用过的 / 自定义）

### 改进

- 设置页重新分类：新增「常规」页（语言、启动与退出、检查更新、数据位置），连接、文件传输、安全、同步等页面按分组整理
- 「恢复默认」改成只恢复当前页面的设置，不会再连带改掉语言、终端字体等其他设置
- 没检测到系统的 SSH 主机显示 ZeeTerm 图标
- 只有隐藏文件的目录会提示「空目录（N 个隐藏文件）」，可以一键显示
- 下载符号链接时，下载的是它指向的文件或目录
- 侧栏左下角去掉了钥匙按钮，凭据在「设置」里
- 任务栏图标在深色任务栏上更清楚

### 修复

- 终端里右键「打开链接」不再导致程序卡死退出
- 「保存并关闭」时，保存进行中又输入的内容不会再丢失
- 下载符号链接不会再只存下几个字节
- 传输在最后时刻取消，不会再替换掉目标文件；暂停后的传输不会再卡住不动
- 远程端口转发在启动途中停止，不会再一直占着服务器端口
- 从备份恢复时，同端口、不同监听地址的本地转发不会再丢掉一条
- 替换同步账号中途失败时，保留原来的设置，不留下新旧混合的配置
- 系统没有 APPDATA 环境变量时，数据不会再存进临时文件夹
