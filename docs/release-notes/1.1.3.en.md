ZeeTerm 1.1.3: a global command palette, host import from your SSH config, translucent terminal backgrounds, and new Linux ARM64 and Intel Mac builds

### New

- Command palette: press Ctrl+Shift+P (Cmd+Shift+P on macOS), or Ctrl+K when the focus is not in a terminal. Type a few letters to search open terminal tabs, hosts, quick commands, common actions and every setting, in English or Chinese
- Hosts: import hosts from your OpenSSH config (`~/.ssh/config`). Use "Import from SSH config" at the top of the sidebar, on the Hosts page or on the welcome page, tick the hosts you want in the preview and create them in one go. `Include`, `ProxyJump` (including multi-hop jumps) and `IdentityFile` are understood (only the key path is stored; the key is never read), and your ssh files are never changed
- Terminal: the terminal background can be made translucent so the desktop shows through (Settings → Appearance → Terminal Translucency), with blur, plain transparency, or Mica on Windows 11. Only the terminal area becomes translucent, and the default looks exactly as before
- Terminal: you can edit the text in the multi-line paste confirmation before pasting it (Ctrl+Enter pastes); when it contains Markdown code fences, one click removes the fence lines
- AI: select text in the terminal and choose "Ask AI" from the context menu; code blocks in AI replies can be saved as a quick command in one click
- Port forwarding: in "All Network Connections", right-click a port the server is listening on to forward it to your computer in one step; a free local port is picked for you
- Process list: the context menu has new "Copy Command Line" (the full command line, not the shortened one shown in the list) and "Copy PID" items
- Feedback: Settings → About has new "Report a Problem" and "Suggest a Feature" buttons that open a GitHub page in your browser with the version and system details filled in. After a crash, ZeeTerm asks on the next start whether you want to report it; IP addresses, email addresses, host addresses, user names and similar details in the crash log are replaced, and you can review everything before submitting. ZeeTerm itself sends nothing over the network
- New platforms (preview): Linux ARM64 (aarch64) `.deb` and `.tar.gz` packages with in-app updates, and an Intel Mac build (see the macOS section below)

### Changed

- The portable zip and the Linux tar.gz no longer carry the transitional `zssh-mcp` copy from the previous release

### Fixed

- Short in-app notices, such as after copying an address, now appear centered at the top of the window instead of under the window buttons at the top right
- Updates: a Linux tar.gz package is checked for the right version and architecture before it is unpacked, so a validly signed package meant for another version or architecture is rejected

### macOS (Apple Silicon / Intel, preview)

- Requires an Apple Silicon Mac (M1 or newer) or an Intel Mac running macOS 14 or newer. The Intel build is not a Universal binary: download the zip that matches your Mac (`-macos-arm64.zip` or `-macos-x64.zip`).
- The app is not signed with an Apple Developer ID and is not notarized, so macOS blocks the first launch (saying the developer cannot be verified, or that the app is damaged): run `xattr -dr com.apple.quarantine /Applications/ZeeTerm.app` in Terminal and open it again, or double-click it once and then click "Open Anyway" in System Settings → Privacy & Security (since macOS 15, right-click → Open no longer bypasses this).
- Because the app only carries an ad-hoc signature, macOS may ask whether "ZeeTerm wants to use the keychain" the first time you start each newly updated version: choose "Always Allow".
- On Apple Silicon, install with Homebrew: `brew install --cask moeshinx/tap/zeeterm` (update with `brew upgrade --cask zeeterm`; the first launch still has to be allowed once). The cask does not offer the Intel build yet; on an Intel Mac, download the `-macos-x64.zip` and install it manually.
- ZeeTerm only tells you when a new version is out and does not update itself on macOS: download it from the releases page, or upgrade with Homebrew.

### Android (beta)

- ZeeTerm now has an Android beta for Android 8.0 or newer. The APK is not on this releases page; get it from the download page on the website: https://zeeterm.app/download#android
- The beta is still being polished and may be unstable. Please report problems on GitHub Issues.
