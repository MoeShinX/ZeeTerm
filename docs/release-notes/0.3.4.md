ZeeTerm 0.3.4：安全加固、锁屏增强、更清楚的图标

### 新功能

- 锁屏可以设为「启动时锁定」（设置 → 锁屏，默认关闭）
- 开启锁屏后，查看或复制保存的密码前要先输入锁屏密码，5 分钟内不再重复询问
- 忘记锁屏密码时，可以在锁屏页验证 Windows 账户后重设

### 改进

- 任务栏和托盘图标放大、更清楚
- 锁屏时，已经显示出来的密码会重新遮住
- 服务器的主机密钥换了类型时，会用醒目的警告提示，按 Enter 默认取消
- AI「只读自动」模式下，读取环境变量、密钥配置这类命令改为先问你
- 文件传输等待服务器响应的时间放宽，慢速网络下不容易超时
- 安装包更小

### 修复

- 「测试连接」不再把保存的密码发给还没核对过指纹的主机
- 断点续传不会再接在不完整的文件上
- 删除一台主机的指纹时，不再连带删掉写在同一行的其他主机
- 从托盘点「检查更新」时，窗口会出现在最前面
