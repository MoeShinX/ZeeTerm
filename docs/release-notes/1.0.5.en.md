ZeeTerm 1.0.5: switch to a Chinese input method in the terminal, Tab completion keeps focus, the host info panel can be edited in place, new credentials open in a dialog, plus a large batch of stability and security fixes

### Improved

- Host info panel: click a value to copy that row; double-click the name, address, user or port to edit it in place, then press Enter or click elsewhere to save (protocol, password, jump host and proxy are still edited from "Properties…" in the context menu)
- Settings → Credentials: "New Password", "Key File" and "Import Key" open a dialog (Enter saves, Esc cancels), so the form is never out of sight when you have many credentials
- The new / edit host dialog can be closed by clicking outside it; if you have unsaved changes, it asks first
- Files: typing in the filter box no longer lags in very large folders
- Terminal: hovering a link shows the address it really points to, so a link whose text differs from its target is easy to spot
- Terminal: Ctrl+Shift+R asks first while the session is connected, so a running command is not cut off by accident
- SSH: when a saved password is rejected and you type a new one, you can tick "update the saved password"

### Fixed

- Terminal: pressing Tab / Shift+Tab to complete no longer moves focus to another control
- Settings → Connections & Network no longer freezes for a few seconds the first time it opens
- The server overview is no longer squeezed out of shape when the AI or file panel is open next to it
- The welcome page and the lock screen show the new logo, sharp on high-DPI screens too
- Files: when extracting into a folder named after the archive, special text in the archive's file name can no longer be run as a command on the server
- Terminal: you can switch to a Chinese (or other) input method and type again (the terminal still starts in English; use your input method's switch key)
- Changing the interface language or other settings no longer turns a light UI dark
- Terminal: AltGr characters such as `@ \ ~ { } [ ]` on German, French and similar layouts are typed correctly; the screen no longer freezes when the server disconnects mid-update
- Inline edits in the host info panel can be cancelled with Esc, and an unchanged value no longer shows "Saved"
- Tray: cancelling "Quit" in the confirmation no longer leaves the tray menu unresponsive
- Files: changing permissions keeps setuid / setgid / sticky bits; uploading files such as private keys no longer widens their permissions; extraction refuses symlinks pointing outside the target folder; a file name in an unusual encoding no longer fails the whole transfer
- SSH: if the saved password is rejected you are asked again; login prompts sent by the server are marked as coming from the server; a different capitalisation of the host name can no longer bypass the fingerprint check
- AI assistant: after "Stop", commands the agent sends are no longer run; commands split across lines ask first in read-only mode
- AI assistant: switching to "Allow All" in Settings also asks first; a custom endpoint on a non-local http address shows that the API key would be sent in plain text
- Sync: no longer takes a backup on every sync; OneDrive storage is identified by account ID (the first sync after upgrading is treated as a first sync and keeps data on both sides); forgetting a host fingerprint on one device now syncs to the others

Thanks to youbilin for contributing several of the improvements in this release.

### macOS preview (Apple Silicon)

- Download `ZeeTerm-1.0.5-macos-arm64.zip`, unzip it and drag ZeeTerm into Applications; macOS 14 or later is required. Or use Homebrew: `brew install --cask moeshinx/tap/zeeterm` (update with `brew upgrade --cask zeeterm`)
- This build is **not yet signed or notarized by Apple**: the first time you open it, go to System Settings → Privacy & Security and click "Open Anyway"
- In-app updates are not available on macOS yet: when a new version is out, ZeeTerm tells you and opens the download page
