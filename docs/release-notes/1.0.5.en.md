ZeeTerm 1.0.5: Tab completion in the terminal keeps focus, the host info panel can be edited in place, new credentials open in a dialog, the new logo on the welcome page, plus a few usability fixes

### Improved

- Host info panel: click a value to copy that row; double-click the name, address, user or port to edit it in place, then press Enter or click elsewhere to save (protocol, password, jump host and proxy are still edited from "Properties…" in the context menu)
- Settings → Credentials: "New Password", "Key File" and "Import Key" open a dialog (Enter saves, Esc cancels), so the form is never out of sight when you have many credentials
- The new / edit host dialog can be closed by clicking outside it; if you have unsaved changes, it asks first

### Fixed

- Terminal: pressing Tab / Shift+Tab to complete no longer moves focus to another control
- Settings → Connections & Network no longer freezes for a few seconds the first time it opens
- The server overview is no longer squeezed out of shape when the AI or file panel is open next to it
- The welcome page and the lock screen show the new logo, sharp on high-DPI screens too

Thanks to youbilin for contributing several of the improvements in this release.

### macOS preview (Apple Silicon)

- Download `ZeeTerm-1.0.5-macos-arm64.zip`, unzip it and drag ZeeTerm into Applications; macOS 14 or later is required. Or use Homebrew: `brew install --cask moeshinx/tap/zeeterm` (update with `brew upgrade --cask zeeterm`)
- This build is **not yet signed or notarized by Apple**: the first time you open it, go to System Settings → Privacy & Security and click "Open Anyway"
- In-app updates are not available on macOS yet: when a new version is out, ZeeTerm tells you and opens the download page
