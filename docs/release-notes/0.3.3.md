ZeeTerm 0.3.3：多个云端备份、默认用 ZeePilot，以及一批细节打磨

### 新功能

- 云端备份：除了主同步，还能再加最多 5 个云端备份（WebDAV / S3 / GitHub Gist / OneDrive），主同步成功后自动上传，也可以手动「立即备份」或「从这里恢复」
- 侧栏「属性」面板显示保存的密码（默认隐藏，点眼睛才显示）

### 改进

- AI 助手默认使用内置的 ZeePilot；以前没有手动选过智能体的，升级后也会切到 ZeePilot，可在 设置 → AI 改回
- 本地备份和导出的备份文件会带上同步账号设置，恢复后不用重新填写（同步到云端的内容依旧不含这些账号信息）
- OneDrive 同步开箱即用，不用再自己注册应用
- 本地备份的「最多保留份数」改成直接输入，默认 5 份
- 「属性」面板里的地址、用户名等可以直接用鼠标选中复制
- 鼠标放在会话标签上显示这台主机的地址
- 会话标签上不再显示系统图标，更清爽
- 终端光标默认改为下划线

### 修复

- 在服务器概览面板上滚动鼠标，下面的终端不再跟着滚动
