ZeeTerm 1.0.8：SSH 意外断开后自动重连、关闭正在使用的连接前先确认，界面字号可以调了

### 新增

- 终端：SSH 连接意外断开（网络中断、保活超时、服务器重启）后会自动重连（设置 → 终端 →「自动重连」，默认打开）。断线画面上会显示「N 秒后自动重连（第 k 次）」，先等 3 秒，之后间隔逐渐拉长到 30 秒，最多试 10 次（大约 4 分钟）；仍然可以按 R 或点画面手动重连，也可以点「取消」停下。远端 shell 正常退出（比如输入 exit）、你主动断开、Telnet 和串口不会自动重连；遇到密码错误、主机密钥不符这类需要你处理的情况会立刻停下，不会反复弹窗。重连后之前的输出都还在
- 终端：手动关闭正在使用的连接前先确认（设置 → 终端 →「关闭标签前确认」，默认打开）。关标签、关窗格、批量关闭（关闭其他 / 左侧 / 右侧 / 全部）、关独立终端窗口时，只要里面有已连上或正在连接的会话，就先弹一个确认框，写明会断开几个连接；回车关闭、Esc 取消，勾上「不再询问」就不再弹。已断开的标签照旧直接关
- 界面：设置 → 外观里新增「界面字号」，分「小 / 标准 / 大」三档（默认「标准」，和以前一样），选中立即生效，所有打开的窗口一起变。它只管界面文字，终端字号仍在「终端」里单独设置

### 修复

- 服务器概览：内存、交换空间、磁盘不到 1 GB 时按 MB 显示（如「512MB」），不再显示成「0.5GB」「0.1GB」

### macOS 预览版（Apple Silicon）

- 1.0.8 的 macOS 版稍后提供。在此之前，macOS 请继续使用 1.0.6：在 GitHub 发布页的 1.0.6 下载 `ZeeTerm-1.0.6-macos-arm64.zip`，或者用 Homebrew：`brew install --cask moeshinx/tap/zeeterm`
